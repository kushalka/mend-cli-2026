A command-line patch applier for AI-generated edits. It reads unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits, finds the named lines with three-tier fallback matching, and writes all changes or none.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```

`SPEC.md` is the full contract. `runner.ts` is the kit's trial runner, kept unchanged. `check.ts` replays the public practice set.
